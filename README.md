# Fixazo · presentación

Pitch de Fixazo para Hack the Andes 2026 (track Educación Escolar). Es una página estática: `index.html` y la carpeta `img/`.

- Se avanza con las flechas, con un clic o deslizando. La tecla **N** muestra las notas de cada lámina.
- Se publica en Vercel con cada push a `main`.

Producto: https://nawinchay-voice-mvp.vercel.app/ · Código: https://github.com/OmarRocaCuya/Fixazo (rama `periodico`)
